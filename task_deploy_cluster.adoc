= 使用 Web UI 部署 ONTAP Select 叢集
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
您可以使用 ONTAP Select Deploy 管理公用程式提供的 Web 使用者介面來部署單節點或多節點 ONTAP Select 叢集。

使用 Deploy 公用程式 Web 介面建立 ONTAP Select 叢集時、系統會引導您完成一系列特定步驟。確切的程序會因您部署單節點或多節點叢集而有所不同。


TIP: 您還可以link:https://docs.netapp.com/us-en/ontap-select/task_cli_deploy_cluster.html["使用 Deploy 實用程式 CLI 部署 ONTAP Select 叢集"]。



[[step-1-prepare-for-the-deployment]]
[[prepare-for-deploy]]
== 步驟 1：準備部署

做好部署準備，確保部署成功。

.步驟
. 初步規劃。
+
檢閱 link:concept_workflow_deploy.html["方案"] 和 link:concept_lic_evaluation.html["授權"] 區段。根據此檢閱結果，您可以針對叢集做出決策，包括：

+
** Hypervisor
** 節點數量
** 授權類型
** 平台大小（執行個體類型）
** ONTAP Select 版本


. 準備主機。
+
您必須準備好執行 ONTAP Select 節點的 Hypervisor 主機，並根據您的授權模式準備好所需的儲存授權檔案。若要檢視準備需求：

+
.. 登入 Deploy Web 使用者介面。
.. 在頁面頂端選取 image:icon_question_mark.gif["問號"]。
.. 選取 *Prerequisites* 。
.. 向下捲動以檢閱需求，然後選取 *OK*。


. 取得授權檔案。
+
如果您打算在正式作業環境中部署叢集，則必須根據您的授權模式取得儲存授權檔案。

. 部署安裝和帳戶認證資料。
+
link:task_install_deploy.html["安裝 Deploy 管理公用程式並執行初始組態"]。您需要擁有在安裝過程中配置的 Deploy 管理員帳戶的密碼。

. （選用）安裝較早的 ONTAP Select 節點映像。
+
根據預設，Deploy 管理公用程式包含發佈時最新版本的 ONTAP Select。如果您想要使用較早版本的 ONTAP Select 部署叢集，則需要link:task_cli_deploy_image_add.html["將 ONTAP Select 映像新增至您的 Deploy 執行個體"]。

. 了解「入門」啟動頁面。
+
初始頁面 *Getting Started with ONTAP Select Deploy* 將引導您完成建立叢集的多步驟流程。該過程包含五個主要步驟，其中包括：

+
** 新增授權
** 將主機新增至清單
** 建立叢集
** 網路預先檢查
** 部署叢集
+

NOTE: 您可以透過選擇頁面頂部的標籤 (Clusters、Hypervisor Hosts、Administration) 獨立執行相同的步驟。



. 檢閱網路檢查程式。
+
如果您要部署多節點叢集，則應該熟悉網路檢查器。您可以使用 link:task_adm_connectivity.html["Web UI"] 或 link:task_cli_connectivity.html["CLI"] 執行網路連線檢查器。





[[step-2-create-a-single-node-or-multi-node-cluster]]
[[create-single-or-multi-node-cluster]]
== 步驟 2：建立單節點或多節點叢集

您可以使用 ONTAP Select Deploy Web 使用者介面來部署單節點或多節點 ONTAP Select 叢集。

.開始之前
請確認您已安裝 Deploy 管理程式並完成了初始設定（密碼、AutoSupport 和 vCenter）。

.關於此任務
建立一個包含一個或多個節點的 ONTAP Select 叢集，用於正式作業部署。

.步驟
您需要遵循的步驟取決於您要建立的是單節點叢集還是多節點叢集。多節點叢集可以包含兩個、四個、六個、八個、十個或十二個節點。

[role="tabbed-block"]
====
.單節點叢集
--
. 使用系統管理員帳戶（admin）透過 Web 介面登入 Deploy 公用程式。
. 如果顯示 *Welcome to ONTAP Select* 彈出視窗，請確認您已符合組態先決條件，然後選取 *OK* 。
. 如果未顯示 *Getting Started* 叢集啟動頁面，請在頁面頂端選取 image:icon_question_mark.gif["問號"]，然後選取 *Getting Started*。
. 在 *Getting Started* 頁面上、選取 *Upload* 、然後從本機工作站選取授權、並選取 *Open* 以上傳授權。
. 選取 *Refresh* 並確認授權已新增。
. 選取 *Next* 以新增 Hypervisor 主機，然後選取 *Add* 。
+
您可以直接新增 Hypervisor 主機，也可以透過連接到 vCenter 伺服器來新增。請根據需要提供相應的主機詳細資訊和認證資料。

. 選擇 *Refresh* ，並確認主機的 *Type* 值為 *ESX* 或 *KVM* 。
+
您提供的任何帳戶認證資料都會新增至 Deploy 認證資料庫。

. 選取 *Next* 以開始叢集建立程序。
. 在 *Cluster Details* 區段中、提供描述叢集所需的所有資訊、然後選取 *Done* 。
. 在 *Node Setup* 下，提供節點管理 IP 位址並選擇節點的授權；如有需要，您可以上傳新的授權。如有需要，您也可以變更節點名稱。
. 提供 *Hypervisor* 和 *Network* 配置。
+
共有三種節點配置，分別定義了虛擬機器的大小和可用功能集。這些執行個體類型分別由您購買的授權的標準版、進階版和進階 XL 版支援。您為節點選擇的授權必須符合或超過執行個體類型。

+
選擇 hypervisor 主機以及管理網路和資料網路。

. 提供 *Storage* 組態，然後選取 *Done* 。
+
您可以根據平台授權等級和主機組態選擇磁碟機。

. 檢閱並確認叢集的組態。
+
您可以在適用的部分中選取image:icon_pencil.gif["編輯"]來變更組態。

. 選擇 *Next* ，然後提供 ONTAP 管理員密碼。
. 選擇 *Create Cluster* 開始叢集建立過程，然後在彈出視窗中選擇 *OK*。
+
建立叢集最多可能需要 30 分鐘。

. 監控多步驟叢集建立程序，以確認叢集已成功建立。
+
頁面會定期自動重新整理。



--
.多節點叢集
--
. 使用系統管理員帳戶（admin）透過 Web 介面登入 Deploy 公用程式。
. 如果顯示 *Welcome to ONTAP Select* 彈出視窗，請確認您已符合組態先決條件，然後選取 *OK* 。
. 如果未顯示 *Getting Started* 叢集啟動頁面，請在頁面頂端選取 image:icon_question_mark.gif["問號"]，然後選取 *Getting Started*。
. 在 *Getting Started* 頁面上，選取 *Upload*，從本機工作站選取授權，然後選取 *Open* 以上傳授權。重複此操作以新增其他授權。
. 選擇 *Refresh* 並確認授權已新增。
. 選取 *Next* 以新增所有 Hypervisor 主機，然後選取 *Add*。
+
您可以直接新增 Hypervisor 主機，也可以透過連接到 vCenter 伺服器來新增。請根據需要提供相應的主機詳細資訊和認證資料。

. 選擇 *Refresh* ，並確認主機的 *Type* 值為 *ESX* 或 *KVM* 。
+
您提供的任何帳戶認證資料都會新增至 Deploy 認證資料庫。

. 選取 *Next* 以開始叢集建立程序。
. 在 *Cluster Details* 區段中、選取所需的 *Cluster Size* 、提供描述叢集所需的所有資訊、然後選取 *Done* 。
. 在 *Node Setup* 下，提供節點管理 IP 位址並為每個節點選擇授權；如有需要，您可以上傳新的授權。如有需要，您也可以變更節點名稱。
. 提供 *Hypervisor* 和 *Network* 配置。
+
共有三種節點配置，分別定義了虛擬機器的大小和可用功能集。這些執行個體類型分別由您購買的授權的標準版、進階版和進階 XL 版支援。您為節點選擇的授權必須符合或超過執行個體類型。

+
選擇 hypervisor 主機以及管理網路、資料網路和內部網路。

. 提供 *Storage* 組態，然後選取 *Done* 。
+
您可以根據平台授權等級和主機組態選擇磁碟機。

. 檢閱並確認叢集的組態。
+
您可以在適用的部分中選取image:icon_pencil.gif["編輯"]來變更組態。

. 選擇 *Next* ，然後選擇 *Run* 來執行網路預先檢查。這將驗證為 ONTAP 叢集流量選擇的內部網路是否正常運作。
. 選擇 *Next* ，然後提供 ONTAP 管理員密碼。
. 選擇 *Create Cluster* 開始叢集建立過程，然後在彈出視窗中選擇 *OK* 。
+
建立叢集最多可能需要 45 分鐘。

. 監控多步驟叢集建立程序，以確認叢集已成功建立。
+
頁面會定期自動重新整理。



--
====


[[step-3-complete-the-deployment]]
== 步驟 3：完成部署

部署叢集之後、link:https://docs.netapp.com/us-en/ontap/system-admin/setup-autosupport-task.html["確認 ONTAP Select AutoSupport 功能已配置"^]然後link:task_cli_clusters.html["備份 ONTAP Select Deploy 組態資料"]。

[TIP]
====
如果叢集建立作業已啟動但未能完成，則您定義的 ONTAP 管理密碼可能無法生效。如果發生這種情況，您可以使用下列 CLI 命令來確定 ONTAP Select 叢集的臨時管理密碼：

[source, cli]
----
(ONTAPdeploy) !/opt/netapp/tools/get_cluster_temp_credentials --cluster-name my_cluster
----
====
