= ONTAP Select 的授權購買工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
以下工作流程說明如何為您的 ONTAP Select 部署購買和應用授權。購買授權時，您必須選擇授權模式和儲存容量。

確切的程序會因您使用的是 Capacity Tier 或 Capacity Pool 授權而有所不同：

九位數授權序號:: 序號適用於節點（Capacity Tiers）或儲存池（Capacity Pools）
授權鎖定 ID:: 使用 Capacity Pool 授權時，您必須擁有 Deploy 執行個體的授權鎖定 ID
授權網站:: 您可以在不同的網站上取得 Capacity Tier 和 Capacity Pool 授權。
