= ONTAP Select Deploy 公用程式安裝所需資訊
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
在虛擬機器管理程式環境中安裝 Deploy 管理公用程式之前，請檢閱所需的組態資訊和選用的網路組態資訊，以便為成功部署做好準備。



[[required-configuration-information]]
== 所需組態資訊

作為部署計劃的一部分，您應該在安裝 ONTAP Select Deploy 管理實用程式之前確定所需的組態資訊。

[cols="40,60"]
|===
| 必要資訊 | 說明 


| Deploy 虛擬機器的名稱 | 用於虛擬機器的識別碼。 


| Hypervisor 主機的名稱 | 安裝 Deploy 公用程式的 VMware ESXi 或 KVM Hypervisor 主機識別碼。 


| 資料儲存區的名稱 | 用於儲存虛擬機器檔案的 Hypervisor 資料存放區識別碼（大約需要 40GB）。 


| 虛擬機器的網路 | Deploy 虛擬機器所連接之網路的識別碼。 
|===


[[optional-network-configuration-information]]
== 選用的網路組態資訊

Deploy 虛擬機器預設使用 DHCP 進行設定。但是，如有需要，您可以手動設定虛擬機器的網路介面。

[cols="35,65"]
|===
| 網路資訊 | 說明 


| 主機名稱 | 主機的識別碼。 


| 主機 IP 位址 | 主機的靜態 IPv4 位址。 


| 子網路遮罩 | 子網路遮罩，根據虛擬機器所屬的網路。 


| 閘道 | 預設閘道或路由器。 


| 主要 DNS 伺服器 | 主要網域名稱伺服器。 


| 次要 DNS 伺服器 | 次要網域名稱伺服器。 


| 搜尋網域 | 要使用的搜尋網域清單。 
|===
