= 升級 ONTAP Select Deploy 執行個體
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用 ONTAP Select Deploy 實用程式 CLI 就地升級現有的 ONTAP Select Deploy 實用程式虛擬機器。

您可以從 ONTAP Select Deploy 9.18.1 或 9.17.1 直接升級到 ONTAP Select Deploy 9.19.1。要從更早的版本（例如 ONTAP Select Deploy 9.16.1）升級，您必須先升級到 ONTAP Select Deploy 9.17.1 或 9.18.1，然後再升級到 ONTAP Select Deploy 9.19.1。

[NOTE]
====
如果您安裝的是舊版的 ONTAP Select Deploy 管理公用程式，則應升級至最新版本。您可以獨立升級 ONTAP Select 節點和 ONTAP Select Deploy 元件。如需更多詳細資訊，請參閱 link:concept_adm_upgrading_nodes.html["升級 ONTAP Select 節點"^]。

====
.開始之前
確認在升級過程中 ONTAP Select Deploy 未用於執行任何其他任務。



[[step-1-download-the-upgrade-package]]
== 步驟 1：下載升級套件

若要開始升級過程，請從 NetApp 支援網站下載 ONTAP Select Deploy 升級檔案。升級套件的格式為單一壓縮檔案。

.步驟
. 存取 link:https://mysupport.netapp.com/site/downloads/["NetApp 支援網站下載"^] 頁面。
. 向下捲動並選擇 *ONTAP Select Deploy*。
. 選擇所需的 ONTAP Select 版本。
. 檢閱終端使用者授權合約（EULA），然後選取 *Accept & Continue*。
. 選擇並下載適當的 *ONTAP Select Deploy Upgrade* 套件。視需要回應所有提示。




[[step-2-upload-the-package-to-the-ontap-select-deploy-virtual-machine]]
== 步驟 2：將套件上傳至 ONTAP Select Deploy 虛擬機器

下載軟體包後，您需要將檔案上傳到 ONTAP Select Deploy 虛擬機器。

.關於此任務
本任務介紹了一種將檔案上傳到 ONTAP Select Deploy 虛擬機器的方法。可能還有其他更適合您環境的選項。

.開始之前
* 確認升級檔案可在本機工作站上使用。
* 請確認您擁有管理員使用者帳號的密碼。


.步驟
在本機工作站的命令 shell 中，使用 `scp`（Secure Copy Protocol）公用程式將映像檔上傳到 ONTAP Select Deploy 虛擬機器，如下列範例所示：

....
scp ONTAPdeploy2.12_upgrade.tar.gz admin@10.228.162.221:/home/admin (provide password when prompted)
....
.結果
升級檔案儲存在 admin 使用者的主目錄中。



[[step-3-apply-the-upgrade-package]]
== 步驟 3：套用升級套件

將升級檔案上傳到 ONTAP Select Deploy 虛擬機器後，即可套用升級。

.開始之前
* 確認升級檔案在 ONTAP Select Deploy 公用程式虛擬機器中的放置目錄。
* 確認在執行升級時，ONTAP Select Deploy 未用於執行任何其他任務。


.步驟
. 使用系統管理員帳戶透過 SSH 登入 ONTAP Select Deploy 公用程式 CLI。
. 使用適當的目錄路徑和檔案名稱執行升級：
+
[source, cli]
----
deploy upgrade -package-path <file_path>
----
+
範例命令：

+
....
deploy upgrade -package-path /home/admin/ONTAPdeploy2.12_upgrade.tar.gz
....


.完成後
升級程序完成前，系統會提示您建立 ONTAP Select Deploy 虛擬機器組態的備份。此外，您還應該清除瀏覽器快取，以便檢視新建立的 ONTAP Select Deploy 頁面。
